# 【腾讯位置服务开发者征文大赛】参赛优化计划 - Emotion Map

本计划旨在通过深度集成腾讯位置服务（Tencent LBS）的核心能力，将“城市情绪地图 (Emotion Map)”打造成一个具备高技术含金量、强视觉冲击力和实际应用价值的参赛作品。

## 参赛目标
- **核心目标**：冲刺一等奖（Insta360 运动相机）。
- **技术目标**：深度使用 TMap API GL、可视化库、Service 服务库。
- **内容目标**：输出一篇 >2000 字的高质量技术博文，展示 LBS 在城市数字化中的应用。

## 重点升级功能 (Tencent LBS 深度集成)

### 1. 智能地点搜索与关联 (WebService & Search Service)
- **功能**：在心情打卡面板增加地点搜索功能。
- **技术点**：集成 `TMap.service.Search`，实现关键词联想和周边 POI 检索。
- **价值**：将情绪从单纯的“坐标”提升到“具体的地理场景”。

### 2. 逆地址解析 (Reverse Geocoding)
- **功能**：自动获取当前位置的详细街道/地标名称。
- **技术点**：使用 `TMap.service.Geocoder` 的 `getAddress` 接口。
- **价值**：提升交互体验，自动填入位置描述。

### 3. 高级可视化升级 (Visual Layer)
- **功能**：增加点聚合（Cluster）模式，并优化热力图平滑度。
- **技术点**：
    - 使用 `TMap.visual.Layer.Cluster` 处理密集数据。
    - 动态切换热力图梯度颜色（根据选择的情绪类型切换底色）。
- **价值**：展示对海量空间数据处理的能力。

### 4. 个性化地图样式 (Map Style)
- **功能**：根据情绪氛围动态切换底图样式。
- **技术点**：在官网控制台创建自定义样式，通过 `mapStyleId` 动态更新。
- **价值**：视觉美感加分，符合“情绪”主题。
